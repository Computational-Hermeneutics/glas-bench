wordfreq, version 2

Counts the words in a text file and prints the most frequent.

    python wordfreq.py [-s] [-n N] FILE

  -s    leave out common words (the, a, of ...)
  -n N  print the N most frequent (10 if not given)

The reading of words is in textutil.py.

An example for the research bench template: invented, not a historical program.
